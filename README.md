# OBSCURA

Портфоліо-сайт тату-майстра українською мовою.

## Завантаження на GitHub

Завантажте весь вміст цієї папки в корінь репозиторію. Папки `node_modules`, `.next` та `out` завантажувати не потрібно.

## Локальний запуск

```bash
npm install
npm run dev
```

## Статична збірка

```bash
npm run build
```

Готові файли для GitHub Pages з’являться у папці `out`.
